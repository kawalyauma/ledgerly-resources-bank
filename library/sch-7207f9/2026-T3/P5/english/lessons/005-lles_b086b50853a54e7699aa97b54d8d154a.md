# TOPIC: PEACE AND SECURITY
## SUB-TOPIC: Using so … that — Joining sentences using so … that
### So … that
- Very means extremely.
- Too or so can mean the same as very.
- We use so … that to emphasize quality.
### Examples of sentences
- The girl is so fat that she cannot run.
- Our teacher is so good that all pupils love her.
### Example 1
- The village has very many thieves.
- There is no peace.
- The village has so many thieves that there is no peace.
### Example 2
- Mary was very weak.
- She didn’t go to police to report the matter.
- Mary was so weak that she didn’t go to police to report the matter.
