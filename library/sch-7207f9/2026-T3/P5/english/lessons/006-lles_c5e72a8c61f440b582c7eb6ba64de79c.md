# TOPIC: PEACE AND SECURITY
## SUB-TOPIC: Sentence joining practice — Joining sentences using so … that
### Remember
- When something is in a high degree, we use the word ‘very’.
- ‘Very’ also means ‘extremely’.
- ‘Too’ or ‘so’ can mean the same.
- We use so … that to emphasize quality.
### Example 1
- The village has very many thieves.
- There is no peace.
- The village has so many thieves that there is no peace.
### Example 2
- Our village is very peaceful.
- You cannot find any robber in it.
- Our village is so peaceful that you cannot find any robber in it.
